# Coverage Badge Setup

This file documents the coverage badge setup for README integration in Phase 3.

## Codecov Integration

The project is configured to upload coverage reports to Codecov, which will provide:

1. **Coverage Badge URL**: Available at `https://codecov.io/gh/pbassut/napoleon/branch/main/graph/badge.svg`
2. **Coverage Dashboard**: Available at `https://codecov.io/gh/pbassut/napoleon`

## Badge Markdown for README

When Phase 3 is implemented, add this badge to the README.md:

```markdown
[![Coverage Status](https://codecov.io/gh/pbassut/napoleon/branch/main/graph/badge.svg)](https://codecov.io/gh/pbassut/napoleon)
```

## Required Secrets

The following secret must be set in GitHub repository settings:

- `CODECOV_TOKEN`: Get from https://codecov.io/gh/pbassut/napoleon/settings

## Coverage Reports

- **CI Artifacts**: Coverage reports are uploaded as CI artifacts for each Node.js version
- **Codecov Dashboard**: Detailed coverage analysis available on Codecov
- **Local Reports**: Run `npm run test:coverage` to generate local HTML reports in `coverage/` directory

## Quality Gates

- **Minimum Threshold**: 80% coverage required for all metrics (branches, functions, lines, statements)
- **CI Failure**: Builds fail when coverage drops below threshold
- **Pull Request Comments**: Codecov will comment on PRs with coverage changes
